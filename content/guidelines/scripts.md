# 기획·대본

1. 소재 관련 기존 경험·대본·성과를 확인하고 부족한 핵심만 질문한다.
2. [대본 방법](../references/legacy-workspace/Kim.kkun_contents/methods/reels-script.md), [검증 원문](../references/legacy-workspace/Kim.kkun_contents/context/voice-corpus.md)을 읽는다. 빌드인퍼블릭은 [해당 원문](../references/legacy-workspace/Kim.kkun_contents/context/voice-corpus-build.md)도 읽는다.
3. [기존 콘텐츠 지침](../references/legacy-workspace/Kim.kkun_contents/CLAUDE.md)의 영상 길이·30초 기준과 별도 검수 기준, [제작 절차](../references/legacy-workspace/Kim.kkun_contents/methods/workflow.md)의 기획·대본·생산 규칙을 적용한다. 이 문서들의 상위 Projects 진입 안내는 가져오지 않는다.
4. AI 초안·수환 수정 원문·실제 발화본을 구분해 보존한다. 촬영에 쓸 버전과 근거를 작품에서 연결한다. 예상 발화 시간은 실제 영상 시각과 구분한다.

블로그는 해당 요청 또는 확인된 기존 승인 범위에서 [블로그 방법](../references/legacy-workspace/Kim.kkun_contents/methods/longform.md)을 적용한다.
