# 편집·검수

- [편집 취향·기준](../references/legacy-workspace/Kim.kkun_contents/methods/capcut-caption-style.md)과 [단계별 실행 확인](../references/legacy-workspace/Kim.kkun_contents/methods/automation.md#단계별-실행-확인--2026-09-19)을 읽는다. 이전 상태 기록은 현재 서비스 동작의 증거로 쓰지 않는다.
- [기존 영상 편집 세션](../references/legacy-workspace/Kim.kkun_contents/methods/workflow.md#영상-편집-세션)의 원본·사용자 수정본 보존, 비교, 검수 조건을 유지한다.
- 실제 발화와 채택된 비컷 버전으로 편집한다. 전체 출력의 자막·음향·컷 전환을 확인하고, 프로그램이 확인한 파일·경로와 실제 재생 검수 범위를 구분한다.
- CapCut 라이브 프로젝트와 ZIP 보관본·출력 MP4는 서로 다르다. 이번 사본만으로 편집 복원이 검증된 것은 아니다. 외부 미디어 경로·앱 내 재열기·필요한 원본을 먼저 확인한다.
- 기존 편집 기록 검사기는 기존 경로 배치를 전제로 한다. `tools/README.md`를 보고 적용 가능한 대상과 입력을 확인한다. 검사 통과는 취향 적합성이나 전체 편집 성공을 뜻하지 않는다.
