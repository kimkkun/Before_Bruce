# 제작 흐름과 개선

기획·대본 → 비컷 준비·검수 → 수환 촬영·컷 선택 → 편집 → 실제 결과 검수 → 피드백 수정.

| 단계 | 이어받을 정보 |
|---|---|
| 대본에서 비컷 | 사용할 대본·버전, 대사별 장면 목적 |
| 비컷에서 편집 | 채택된 생성 버전, 사용 구간, 남은 문제 |
| 촬영에서 편집 | 실제 발화·원본 경로, 대본과 달라진 부분 |
| 편집에서 검수 | 실제 프로젝트·출력 버전, 확인할 기준 |
| 수정에서 다음 편 | 교정 이유, 이번 편/공통 적용 범위, 다음 확인 사항 |

현재 상태는 작품의 기존 상세 기록에 두고 `work.md`에서 연결한다. 새 작품은 `work.md` 하나에서 시작한다. 모든 단계에 사용자 재승인을 추가하지 않으며, 중요한 내용·취향 결정과 비용·게시 등은 실제 승인 범위를 따른다.

실패하면 입력 부족·기준 누락·적용 실패·도구 한계·완료 기준 모호성 중 원인을 먼저 확인한다. 필요한 최소 변경으로 실패 사례와 기존 정상 사례를 확인하고, 다음 관련 제작에서 재작업과 사용자 교정이 줄었는지 본다. 성공·실패를 전부 공통 규칙으로 만들지 않는다.

과거 상세 실행 근거는 [기존 workflow](../references/legacy-workspace/Kim.kkun_contents/methods/workflow.md)에 있다. 이번 정리는 파일 관리의 통합이며 무인 생성·자동 편집·자동 게시를 새로 설치한 것이 아니다.
