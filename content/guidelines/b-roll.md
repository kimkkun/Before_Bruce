# 비컷 제작

- [제작 방식 안내](../references/legacy-workspace/Higgsfield/README.md)에서 이번 방식의 README를 읽는다. 내 연기 변환·상황 생성·인물 기반 생성의 기준을 섞지 않는다.
- [기존 제작 흐름](../references/legacy-workspace/Kim.kkun_contents/methods/workflow.md)의 「대본부터 비컷·편집까지」가 기존 결정의 근거다. 대본 확정 후 기본 3~5장면, 편당 150크레딧 상한은 문서의 대상·조건·누적 사용액을 대조해 적용한다. 새 편이라고 임의의 비용 권한을 확대하거나 같은 편의 예산을 초기화하지 않는다.
- 장면표에 대사·컷 목적·실제 사용 대본을 연결한다. 이미지 검수 후 영상화하고, 사용자 채택 여부와 기술·내용 검수를 구분한다.
- [생성·등록·검사 절차](../references/legacy-workspace/Higgsfield/_templates/README.md)를 읽고 사용한다. 기존 job·버전·입력 파일·비용을 확인해 응답 유실 시 중복 제출하지 않는다.
- 새 작품의 출력 위치는 해당 작품의 작업보관이다. 기존 도구가 요구하는 하위 구조를 사용하며 도구 검증 없이 임의로 바꾸지 않는다. 서비스 모델·연결·잔액은 실행 시 다시 확인한다.
