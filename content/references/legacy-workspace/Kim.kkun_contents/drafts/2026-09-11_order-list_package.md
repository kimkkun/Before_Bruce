# 김꾼 릴스 — 말했는데 주문은 안 됐다

- 2026-09-11 / 모드 C+실물 / AI 초안 보존본. 대본 정본은 [수환 수정 최종본](2026-09-11_order-list_suhwan-edit.md). 수환이 “이게 내가 최종본으로 고친거야 기록해둬”로 확정했으며, 아래 AI 본문은 덮어쓰지 않는다. 촬영·발행 완료는 미확인.
- 수환이 「이주제 아주 좋다. 릴스 대본 써줘봐」로 상황극·문제·발주 기능 연결 방향 승인. [소재 카드](../ideas/2026-09-11_order-list.md).
- 도입은 가상 상황극. 수환 실제 품절 경험은 질문 후 답변 대기이며 자기 실패담으로 쓰지 않았다.
- 9/11 수정 요청: 말로 전달한 예시에 카톡을 놓치는 예시 추가. 두 예시는 상황 설명이며 개인 실화로 주장하지 않는다.

## 제목·POV
- 추천 제목: “사장님, 그거 다 떨어졌어요” 꼭 주문 들어오면 듣습니다
- 제목 대안: 직원은 말했고, 사장은 못 시켰습니다 / 발주가 사장 기억력에 달린 가게
- 영상 상단 POV: 주문 들어왔는데 재료가 없을 때

## 훅 5개
1. ★ 상황형: “사장님, 그거 다 떨어졌어요.” “왜 이제 말해?” “어제 말씀드렸는데요.”
2. 단언형: 직원이 말했어도, 재료 주문은 빠질 수 있습니다.
3. 구조 예고형: 재료가 떨어지기 전에, 발주가 어디서 끊겼는지 보세요.
4. 행동 저격형: “알았어” 하고 돌아섰다면, 주문할 때 그 말이 기억날까요?
5. 죄 전환형: 재료 주문 빠졌다고 직원부터 혼내기 전에, 그 요청이 어디에 남는지 보세요.

## 본문 대본

“사장님, 그거 다 떨어졌어요.”
“왜 이제 말해?”
“어제 말씀드렸는데요.”

김꾼입니다. 직원은 말했고, 사장님도 들었어요. 그런데 주문은 빠진 거죠. 제가 더크루에서 풀고 싶은 게 이런 틈이에요.

“소스 얼마 안 남았어요” 하면 “어, 알았어” 하잖아요. 그러다 손님 부르고, 배달 오고. 영업 끝나면 “아까 뭐 시키라고 했더라?”

그럼 카톡으로 보내면 될까요?

“사장님, 내일 쓸 소스 두 통 주문해주세요.” 읽고 “이따 시켜야지” 해요. 그런데 그 밑으로 근무 바꿔달라는 얘기, 마감 사진이 쌓이잖아요. 막상 주문할 때는 그 메시지가 위로 밀려 있는 거예요.

직원은 말도 했고, 카톡도 보냈어요. 사장님도 챙기려고 했고요. 그런데 주문할 때 볼 목록을 머릿속이랑 카톡에서 다시 찾아 모아야 하잖아요. 그 사이에 빠지는 거죠.

그래서 더크루 발주는 이렇게 쓰는 거예요.

우리 가게에서 쓰는 상품을 미리 넣어두고, 직원이 재고를 보면서 필요한 수량을 골라 제출해요. 홀에서 올린 것, 주방에서 올린 것이 사장님 주문표에 모입니다. 사장님은 그 표를 보고 거래처에 주문하는 거예요.

직원은 매번 상품명을 안 적어도 되고, 사장님도 흩어진 말을 모을 필요가 줄잖아요.

물론 지금 당장 떨어진 건 바로 알려야죠. 다음 주문부터 빠뜨리지 않도록, 재고를 확인하고 표를 올릴 시간을 정해두세요.

“알았어” 했다고 주문이 들어가진 않잖아요.

사장님 가게는 주문할 재료를 어디에 모으세요? 댓글로 알려주세요.

## 화면 배치
- 도입: 주문 확인 → 냉장고를 여는 가상 상황극. 특정 재료는 실화 확인 전 지어 넣지 않는다.
- 중간: 구두 전달 예시 → 카톡 예시. “소스 두 통” 요청 아래 근무 변경 대화·마감 사진이 쌓이는 연출. 예시 대화로 제작하고 실제 직원 개인정보는 사용하지 않는다.
- 기능 설명: 실제 상품 목록 → 수량 선택·제출 → 사장 주문표. 버튼명과 화면 동선은 촬영 버전에서 확인한다.
- 거래처에 주문하는 것은 사장 행동으로 설명한다. 자동 주문·거래처 전송·주문 완료 추적 화면을 만들지 않는다.

## 캡션
**“말씀드렸는데요” 다음에 남는 건, 서로 다른 기억입니다.**

말로 들은 건 잊고, 카톡으로 받은 건 다른 대화에 밀려요. 바쁜 영업이 끝나면 주문할 것들을 머릿속과 카톡에서 다시 찾아 모아야 하죠.

더크루에서는 매장 상품을 미리 등록하고, 직원이 필요한 수량을 골라 제출해요. 사장은 모인 주문표를 보고 거래처에 주문하고요.

가게에서 재고를 확인하고 발주표를 올릴 시간을 정해보세요. 사장님은 주문할 재료를 어디에 모으세요?
