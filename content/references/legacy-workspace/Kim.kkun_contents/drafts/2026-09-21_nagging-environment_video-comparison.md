# 잔소리보다 환경 — 제작·워크플로우 검증

## 현재 상태 — 이 문서가 정본

- 확인일: 2026-09-21. 사용자 “검증했어? 이 워크플로우가 잘 돌아갈 수 있다는걸? 그리고 그렇게 검증하는 흐름도 있었어?”에 따른 읽기 전용 실물 점검.
- 상태: 비컷 기존 결과 있음·외형 수정 필요·사용자 미채택. 본편 원본 대기. 대본→자동 선제작→채택→촬영본 편집→출력의 전체 연결 시험은 미실시.
- 대본: [전체 대본 v4](2026-09-21_nagging-environment_full-v4.md). 합본 저장을 촬영 확정으로 해석하지 않음.
- 제작 근거: [기존 생성·비용·피드백 기록](../../김꾼_영상보관/2026-09-21_nagging-environment/03_수정기록/제작기록_v001.md). 안경 외형 지적 및 장면/공간 연속성 한계를 해소했다고 간주하지 않음.
- 실제 파일: [해당 편 보관함](../../김꾼_영상보관/2026-09-21_nagging-environment/README.md)의 개별 비컷 4개와 검토 묶음 1개 확인. `01_자료넣는곳`에는 확인 시점 촬영 원본 파일 없음. 이전 보관함의 ‘촬영 원본 보관’ 문구는 실제 원본 접수 증거가 아니었음.
- 도구: Higgsfield 잔액 조회 성공(2800.3크레딧/ultra), CapCut 프로젝트 목록 조회 성공(0919). 읽기 연결 확인이며 생성·삽입·출력 실행 성공으로 확대하지 않음.
- 검사 장애: CapCut `probe_media` 5개 파일 모두 `ffprobe not found in PATH`로 실패. 이 도구 경로의 의존성 문제는 미해결. macOS AVFoundation 대체 검사로 5개 모두 전체 프레임 디코딩 성공. 대체 검사가 해당 도구 자체를 복구한 것은 아님.
- 다음 행동: 기존 외형 피드백·채택 상태 확인 후 필요한 컷만 수정. 촬영본이 제공되면 기존 [한 편→약 세 편 검증 순서](../methods/capcut-caption-style.md#다음-검증-순서--2026-09-11-수환-확정)에 따라 실제 발화·비컷 삽입·음향·출력까지 검증. 새 유료 생성·라이브 편집·원본 이동은 이번 점검에서 실행하지 않음.
- 검증 한계: 기존 생성 이력과 파일 저장/디코딩·도구 조회만 확인. 화면 내용의 재검수, 실시간 전체 재생, 외형 수정, 본편 삽입, 다음 편 재현성, 무인 실행은 미검증. 미확인 단계는 통과로 처리하지 않음.

### 선제작 준비 상태 재점검 — 2026-09-22

수환의 전체 소재·비컷 선제작 및 향후 맥락 연결 질문에 따라 읽기 전용 점검. `python3 -B Higgsfield/tools/artifacts.py check 김꾼_영상보관/2026-09-21_nagging-environment` 통과. 생성 소스 영상 5개와 이들로 만든 검토 4장면을 구분한다. 구조 통과는 입출력 파일·해시·작업 ID·링크 확인이며 편집 준비 완료 판정이 아니다.

컷 기록에 전체 대본 v4 링크와 대응 대사는 있지만 대본 해시가 없고, 검토 모음의 소스 사용구간은 본편 삽입 시각이 아니다. 모든 컷의 외형 수정·사용자 미채택 상태 유지. `01_자료넣는곳`에 촬영 원본 없음. 촬영 후 실제 발화에 맞춘 본편 삽입·출력 시험은 여전히 미실시. 새 생성·수정·라이브 편집은 실행하지 않았다.
