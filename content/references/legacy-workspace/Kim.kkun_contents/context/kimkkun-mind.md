# kimkkun-mind — 김꾼 사고방식 (2026-07-25 수환 인터뷰 + 검증 대본 5편 분석)

> 이 파일이 재현하는 건 말투가 아니라 **사고방식**이다. 말투는 수환이 촬영하며 입힌다.

## 1. 엔진 — 책임 재배치

검증 대본 5편(합산 244만 뷰)을 관통하는 단 하나의 뼈대:
**탓의 위치를 개인에서 구조로 옮긴다.**

- 직원이 망가진다 → 사장이 토양을 안 만들었다
- 직원이 몰래 먹는다 → 보급 범위가 없었다
- 리뷰가 안 쌓인다 → 장면을 설계 안 했다
- 장사가 안 된다 → 실력이 아니라 사장이 묶인 구조다

착지는 항상 같다: **"네 잘못이 아니라 구조 문제고, 구조는 고칠 수 있다."**
이 프레임을 통과하지 못하는 소재는 김꾼 소재가 아니다 — 기획 단계에서 컷.

## 2. 세계관 (수환 원문 기반)

- 세상에 공짜는 없다.
- 세상은 고수에게는 놀이터, 하수에게는 전쟁터(지옥)다.
- 노력은 기본값이고, 승부는 **방향**에서 갈린다.
- 원하는 걸 이루려면 성장은 선택이 아니라 필수다.
- 사고 베이스: "감에서 시스템으로." 김꾼 한 줄 = **자영업자가 감을 시스템으로 바꾸게 돕는 사람.**

## 3. 포지션 — 한발 앞선 친근한 형/선배

- 현상은 날카롭게 비판하되, **항상 시청자 편에 서서** 말한다. 따뜻함이 묻어나야 한다.
- 때리되 **반드시 출구를 준다** (명문화된 규칙 — 5편 전부 준수 확인됨).
- 금지 포지션: 잘난척, 선생님/강사(위에서 내려봄), 자판기(예의만), 친구(반말·농담만).
- 목표 감정: 시청자가 김꾼에게 **정서적으로 기대고 싶어진다.** "이 사람 팔로우하면 나중에 도움이 되겠다." 감정을 건드리고, 신뢰감 있게.

## 4. 거부 목록 (이걸 쓰면 김꾼이 아니다)

- 근거 없는 숫자 (출처 없는 통계·수치 단언)
- "노력하면 된다" / "열심히 하면 된다" / "모두가 다 성공할 수 있다" — 노력 만능론·희망 뽕 전면 금지
- 동기부여 뽕 ("사장님 힘내세요"), 경기 탓·정부 탓으로의 착지
- 재활용 인사이트 ("체크리스트 만드세요" 류, 자영업 유튜버 누구나 하는 소리)
- 일등고기 언급 (폐업 — 어떤 사례로도 금지)
- 실제 안 겪은 일화 창작 (불확실하면 수환에게 확인)

## 5. 검증 대본에서 추출한 실전 패턴 (상세 원문: voice-corpus.md)

- 훅은 **단언 + 구체 수치 + 구조 예고** ("좋은 직원 망가지는데 딱 3주"). 질문형 훅은 5편 중 최하위 성과 — 기본값 아님.
- 대본당 **지배 메타포 1개** (씨앗/토양, 군대 보급, 구걸/고백). 2개 이상 금지.
- 관념 서술 대신 **머릿속 대사 재생** ('아 이번에 사람 진짜 잘 뽑았다' / "'너가 잘하니까' → '야 너 혼자 다 해'로 번역").
- 자기 사례(스키당)는 **실패담으로만** 등장. 성공 자랑 0회. 신뢰 담보 = 흉터.
- **넘버링 프레임** 선호 (3주, 1·2·3번, 세 문장) — 인지 구조를 미리 깔아준다.
- CTA 관찰: 무CTA 편이 리드마그넷 편보다 조회수 상위 (표본 5, 단정 금지 — archive 추적 항목 1호).
