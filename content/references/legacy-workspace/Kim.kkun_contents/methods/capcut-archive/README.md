# CapCut 출력 자동 보관

2026-09-19 수환 요청으로 설치. 매번 보관 요청 없이 출력 영상 사본을 누적한다.

- 대상: ~/Movies/CapCut/ 및 하위 폴더의 MOV/MP4/M4V 중 보관함의 `01_자료넣는곳`을 가진 영상별 폴더명과 소재 ID가 일치하는 파일만. User Data·숨김 폴더는 제외. CapCut 밖의 다른 출력 위치는 제외.
- macOS LaunchAgent com.kimkkun.capcut-export-archive: 로그인 시 및60초마다 실행. Codex 대화 불필요. 전원 종료·로그아웃 중에는 실행되지 않고 다음 로그인 후 확인한다.
- 두 번 이상 검사에서 크기·수정시각이60초 이상 유지되면 복사하고 SHA256 일치를 확인한다. 출력이60초 이상 일시 정지했다 재개되면 중간 버전도 남을 수 있으나 이후 변경본 역시 새 버전으로 저장한다.
- 소재ID와 파일명 일치: 해당 편/99_작업보관/자동보관/. 불명확한 새 출력은 건너뛴다. 과거 미분류는 99_관리자료/과거미분류보관에 보존. 이름·시각·해시별 버전 폴더를 만든다. 기존 출력도 일치하는 대상만 수집한다.
- 동일 내용 중복 방지, 동일 이름 다른 내용은 새 버전 보존. 원래 출력과 기존 버전 삭제 없음.
- 같은 이름의 프로젝트가 있으면 수집 당시JSON과 참조 자료ZIP을 함께 보관한다. 과거 출력과의 정확한 대응·다른 컴퓨터 복원을 자동 보증하지 않는다. 누락은ZIP snapshot-note.json, 실패는manifest.json에 기록. 프로젝트가 없어도 영상은 보관한다.
- 출력 수집은 최종 디자인 확정·발행 판정과 별개. 다음 편집 시작 때 수환 확정본과 비교 기록을 읽는다.
- state.json: 최근 검사·해시·경로·오류. service.log/service-error.log: 서비스 실행 기록.
- 동일 맥 내 사본이며 외부 백업은 아니다.

검증: 안정화 대기·중복 방지·동일명 재출력 버전 보존·미분류 신규 수집 제외·원본 보존 테스트 통과. 실제 실행 결과는 validation.json.

## 설치·복원

정본 코드는 이 Git 폴더에 둔다. 영상은 영상별 작업보관에, 상태·로그는 Projects/김꾼_영상보관/99_관리자료/자동보관에 남겨 Git에 넣지 않는다.

```sh
/usr/bin/python3 methods/capcut-archive/test_archive_exports.py
/usr/bin/python3 methods/capcut-archive/install.py
```

install.py는 현재 위치로 사용자 LaunchAgent를 생성하고 등록한다. 기존 등록이 있으면 중지·재등록하되 출력·보관본·상태 파일은 유지한다. 로그인 중 60초마다 실행한다. 설치는 ~/Library/LaunchAgents 쓰기 권한이 필요하다.
