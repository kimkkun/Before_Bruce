# 소재 카드 — two-schedules (근무표가 두 장)

- 날짜: 2026-08-25 / 상태: **대본화** (수환 "이렇게 써봐" 2026-08-25 → drafts/2026-08-25_two-schedules_package.md)
- 원본 입력 (수환 원문): "터진 구조로 이런 걸 쓰고 싶다. 초반 5초 후킹은 상황을 빠르게 보여주는 것 — '오늘 오후 출근 누구지? / 다음주 화요일에 민수 못 나온다고 하지 않았냐? / 민수야, 찰수랑 지혜 스케줄표 바꿨냐? / 너가 오늘 왜 나왔냐? / 스케줄표 바뀌었어요?' 월수금 오전 오후 다르고, 주말 알바는 또 바뀌고. '스케줄표 정리하느라 정신 없으시죠?'"
- 골격: **에이스 구조** (voice-corpus #6) 변주 — 콜드오픈 스킷 → 죄 전환 재정의 → 고백 10초 → 물리 법칙 → 직원 내면 번역 3단계 → 해법 정의 + 실물(빌드인퍼블릭) → 경구 + CTA

## 뒤집기
- 수환이 하고 싶은 얘기: 근무표 관리가 정신없다 → 더크루가 근무표(스왑) 기능을 만들고 있다
- 사장님이 듣고 싶은 질문으로: **"알바들이 지들끼리 바꾼 근무, 왜 나만 몰랐지?"** — 근무표를 못 짜는 게 아니라 *바뀐 걸 못 잡는* 구조 문제

## 뼈대
- 핵심 주장 (한 줄): 근무표는 짜는 순간부터 틀리기 시작한다. 진짜 근무표는 사장님 손이 아니라 알바 카톡방에 있고, 그 둘이 어긋난 날 사고가 난다.
- 책임 재배치: 통념 [알바들이 지들끼리 막 바꿔서 / 내가 정신이 없어서] → 진짜 [근무표가 사장 머릿속·종이·카톡에 세 갈래로 흩어져 있고, 갱신하는 사람은 사장 한 명뿐인 단일 장애점] → 출구 [바꾸는 건 알바끼리 하되, 바뀐 순간 사장에게 오고 급여까지 같이 따라오는 구조 — "기록이 남는 교환"]
- 지배 메타포 (1개만): **근무표 두 장** — 사장 손에 있는 것 vs 알바 카톡방에 있는 것 (한 사람만 모르는 약속 = 사고)
- 모드 후보: C+실물 (체크리스트·에이스와 같은 계열) — 이유: 빌드인퍼블릭 서사(H3)와 죄 전환 훅(H4) 둘 다 태울 수 있음. 단 근무표는 "기능 소개" 냄새가 강한 소재 → 공지 버튼 편(10/만뷰) 함정. **해법·기능 비중 20% 상한, 파는 건 앱이 아니라 "바뀐 게 기록되는 구조".**

## 블록 초안 (초수는 목표 — 대본 세션에서 정량 검수)

| # | 블록 | 초수 | 내용 후보 |
|---|---|---|---|
| 0 | 콜드오픈 스킷 | 0~5 | 사장: "어? 너 오늘 왜 나왔어?" / 알바: "저 오늘 맞는데요… 지혜랑 바꿨어요" / 사장: "…언제?" — 결과(모르는 스왑) 먼저. 수환 원안 4줄은 5초 초과 → 이 한 장면으로 압축 |
| 1 | 죄 전환 재정의 훅 | ~10 | "알바들이 지들끼리 바꿔서 생긴 일 아니에요. 사장님 가게엔 근무표가 두 장이었던 겁니다. 사장님 손에 한 장, 알바 카톡방에 한 장. 김꾼입니다." |
| 2 | 고백 + 넘버링 | ~12 | "저도 매장 두 개 돌리면서 이걸로 [사고 n번] 났거든요. 근무표가 어긋나는 데는 딱 세 지점이 있습니다." ← **실재 확인 필요** |
| 3 | 물리 법칙 | ~20 | "근무표는 짜는 순간부터 틀리기 시작합니다." 월수금 오전오후 다르고, 주말 또 다르고, 시험·병원·급한 일 — 일주일에 한 번은 반드시 바뀐다. "바꿨어요 / 바꿨어요 / 바꿨어요"(호명 반복 변주). 바뀔 때마다 갱신하는 사람은 딱 한 명 — 사장님 머리가 근무표 서버였던 것 |
| 4 | 직원 내면 번역 3단계 | ~28 | 1단계 "사장님 번거로우실까 봐 저희끼리 바꿨어요"(배려로 시작) → 2단계 카톡방이 진짜 근무표가 됨(사장 버전은 이미 죽은 문서) → 3단계 정산 날 "그날 저 나왔는데요" / "기록엔 없는데?" — 배려로 시작한 게 *내 시간을 안 세는 가게*로 끝남. 마지막 신호 대사 후보: "다음 달부터는 시간 줄여주세요" |
| 5 | 해법 정의 + 실물 | ~20 | 해결은 근무표를 잘 짜는 게 아니라 **바뀐 게 기록되는 것**. 바꾸는 건 알바끼리, 바뀐 순간 사장에게 오고, 급여가 같이 따라온다. "더크루 다음 기능이 이거예요. 지금 만들고 있습니다." ← **아직 없는 기능 — "있다"로 말하면 안 됨** |
| 6 | 경구 + CTA | ~12 | 경구 후보: ① "알바는 근무표를 안 봅니다. 카톡을 봅니다." ② "근무표는 종이가 아니라 약속이에요. 약속이 바뀌었는데 한 사람만 모르면 그게 사고입니다." / CTA: "사장님 가게는 스왑 어떻게 처리하세요? 댓글로 — 기능에 넣습니다" + 베타 100팀 |

- 30초 벽 체크: 고백 10~12초, 실물 암시("두 장" → 해법 예고)는 훅에 이미 심김. CTA는 어차피 95초 뒤 → **고정 댓글로 보완** (에이스 편 교훈)
