# 소재 카드 — order-list

- 날짜: 2026-09-11 / 상태: 수환 수정 대본 최종 확정 → [정본·확정 근거](../drafts/2026-09-11_order-list_suhwan-edit.md).
- 원본 입력: 수환이 「사장님, 그거 다 떨어졌어요」 주제와 상황극·문제·발주 기능 연결 제안을 인용하고 “이주제 아주 좋다. 릴스 대본 써줘봐” 요청.

## 뒤집기
- 하고 싶은 얘기: 더크루 발주 기능 사용법.
- 사장님 질문: 직원이 부족하다고 말했는데 왜 주문할 때 빠질까?

## 뼈대
- 핵심: 말로 들은 요청을 실제 주문할 목록으로 남긴다.
- 책임 재배치: 직원의 전달·사장 기억력 탓 → 요청이 남고 모일 자리와 확인 시간이 없음 → 상품·수량 제출과 주문표 확인 루틴.
- 지배 메타포: 없음. 상황 대사와 실제 목록으로 설명.
- 모드: C+실물. 사장·직원 양쪽 시점 → 제작 이유 → 기능 장면.

## 적재
- 근거·제품 범위: [대본 패키지](../drafts/2026-09-11_order-list_package.md#제품-근거검수)에 연결.
- 업종 예시: 식당 소스 / 카페 우유 / 포장 매장 용기. 모두 예시이며 수환 실화 아님.
- 반론: 당장 품절은 직접 연락해야 한다. 자동 주문이 아니며 사장이 표를 보고 주문한다.
- 수환 경험담: 미확인. 실제 재료·오간 말 질문을 보냈으며 고백은 추가하지 않았다.

## 후속
- 개인 실화는 확인되지 않았으며 최종 대본도 자기 실패담으로 주장하지 않는다. 실제 경험 답변을 최종본 기록의 선행 조건으로 두지 않는다.
- CTA는 운영 방식 댓글 질문. 별도 리드마그넷 없음.
