# 소재 카드 — phone-only (다음 릴스 후보 검토)

- 날짜: 2026-09-09 / 상태: **방향 확정 → 수환 수정본 검수·두 문구 반영, 낭독·제품 안내 확인 대기**
- 원본 입력 (수환): 「다음 릴스 소재를 골라보자. 목표는 더크루에 관심있는 사장님을 모으는거야」
- 작업 범위: 후보 검토 후 수환이 경험과 방향을 확인해 대본 초안까지 진행. 최종 대본·발행은 미승인.
- 개정 대본: [전화만 했다](../drafts/2026-09-02_phone-only_package.md). 9/9 확인된 경험으로 개정. 예전 초안의 미확인 효과·기능·모집 주장은 채택하지 않았다.

## 뒤집기
- 수환의 목표: 더크루에 관심 있는 사장님을 모으기.
- 사장님이 듣고 싶은 질문으로 (제안): **「가게 밖에 나왔는데, 왜 계속 가게에 전화하고 있을까?」**
- 추천 이유: 사장 부재·다점포 운영의 구체적 불편에서 출발해, 더크루가 필요한 이유로 연결하기 쉽다. 가입 효과가 검증된 소재라는 뜻은 아니다.

## 뼈대 — 2026-09-09 방향 확정
- 핵심 주장: 실제 누락 경험이 있으니 잘해놓은 날에도 확인 전화를 반복하게 된다.
- 책임 재배치: 사장의 예민함·직원의 무능 탓에서, 물어봐야 완료 여부를 알 수 있는 구조로 옮긴다. 출구는 확인한 결과를 다음 사람도 볼 수 있게 남기는 것.
- 모드 C. 실제 질문 → 고백 → 반복 확인의 이유 → 확인 결과 공유 → 더크루 제작 이유. 도입과 방향에 수환이 「완벽한거같애 ㅋㅋ」로 동의했다.
- 계곡 편과의 차이: 휴가·원격 운영 전반 대신 실제 누락 경험이 잘해놓은 날의 확인까지 반복시키는 이유에 집중한다.
- 경험 원문: 「아무개 왔냐 물어보는거, 가스불 껏냐?, 브레이크타임 때 에어컨 껏냐?, 그런거지」. 실제 누락 때문에 반복했는지/확인이 안 돼 불안했는지에 「둘 다야 사실」로 확인. 어느 항목이 누락됐는지·횟수·피해·직원의 실제 발언은 미확인이라 추가하지 않는다.

## 후보 비교 — 에이전트 제안
| 순서 | 후보 | 목표와의 연결 | 먼저 풀어야 할 점 |
|---|---|---|---|
| 1 | 매장 밖에서도 계속 확인 전화하는 사장 | 사장 본인이 겪는 시간·운영 문제에서 더크루의 필요로 연결 | 계곡 편도 전화·카톡과 정보 접근 문제를 다뤘다. 같은 질문이 반복된 원인·바꿀 행동이 새로 드러나는 실제 경험인지 확인하고, 새 차이가 없으면 2순위 검토 |
| 2 | 못 끝낸 일을 카톡에 남겼는데 다음 사람이 몰랐다 | 사장이 계속 전달자가 되는 인수인계 문제. 기존 체크리스트·근무표 편과 구분 가능 | 실제 사례와 현행 기획 확인. 인수인계 기능이 이미 완성됐다고 약속하지 않기 |
| 3 | 기록은 빠졌는데 급여 숫자는 멀쩡해 보였다 | 사장·직원이 같은 근거로 시간을 확인해야 하는 문제 | 계산 누락과 실제 미지급을 구분하고 사고 원본·수환 경험을 확인. 전문 급여 해설은 별도 검증 필요 |

## 적재 — 근거와 한계
- [8/20 성과 원본](../metrics/2026-08-20_insta-insights-raw.md): 체크리스트 4만 조회·팔로우 +170, 계곡 1.5만·+50, 공지 2만·+20, 베타 모집 2만·+60. 수환 구두 보고이며 발행 후 경과일이 없어 참고 비교만 가능하다. 이를 소재·구성의 인과 효과로 단정하지 않는다.
- [에이스 3일차 원본](../metrics/2026-08-25_ace-leaves_insta-insights-raw.md): 조회 356,435·팔로우 225, 만뷰당 약 6.31. [7일차 원본](../metrics/2026-08-29_ace-leaves_insta-insights-raw_day7.md)의 40.8만 조회와 3일차 팔로우를 섞어 전환율을 계산하지 않는다.
- **사장 비중·더크루 가입·실사용 전환은 위 성과 자료에서 확인되지 않았다.** 팔로우 증가와 사장 유입은 동일하지 않다. 근무표 두 장의 7일차 자료도 미확보여서 성공·실패 판단을 보류한다.
- 평균시청 시간만으로 특정 시점의 이탈 비율이나 CTA를 본 사람 수를 알 수 없다. 초반에 사장의 문제와 만드는 이유를 연결하는 것은 이번 구성 가설이며, 평균시청을 잔존율·완주율로 바꿔 해석하지 않는다.
- [고객 니즈](../../the-crew-strategy/planning/CUSTOMER-NEEDS.md)의 사장 부재·확장·인수인계 문제, [제품 방향](../../the-crew-strategy/planning/PRODUCT-VISION.md)을 추천의 근거로 참고했다. 출시 상태의 증거는 아니다.
- 대안 소재의 출처: [BIP 소재 풀](2026-08-16_thecrew-bip-topics.md) #10·#3, [제품 규칙](../../the-crew-strategy/planning/PRODUCT-RULES.md), [관련 결정](../../the-crew-strategy/linear/DECISIONS.md). 소재 풀의 당시 개발 우선순위·상태는 현재 사실로 취급하지 않는다.
- 급여 후보의 [사고 원본](../../the-crew-strategy/retrospective/v1-docs/DEBT.md) §8은 옛 퇴근 도장의 출처 정보 누락과 출퇴근 신뢰 처리 비대칭을 원인으로 기록한다. 기존 의사결정 초안의 「안 찍힌 날을 그냥 넘겨서」와 원인 설명이 다르므로 그대로 재사용하지 않는다. 실제 임금 미지급 여부는 별도 확인 전이다.
- 예상 반론: 「전화 대신 카톡 보면 되잖아」 → 실제 사례에서 같은 질문이 왜 반복됐는지 확인한 뒤 답한다. 매장마다 원인이 같다고 단정하지 않는다.
- 수환 경험담: 위 원문 범위로 확인. 앱 사용 후 전화가 사라졌다는 효과는 확인하지 않았다.
- 성과 확인 제안: 사장이라고 밝힌 사람의 구체적 운영 문제 응답·더크루 사용 문의를 구분해 본다. 조회수·팔로우만으로 목표 달성을 판정하지 않는다. 측정 방법은 발행 전 정한다.

## 출고 전에 확인할 것 (이전 초안에서 제외한 주장)
- 9/2 초안의 「9/6 모집 마감」은 지난 날짜다. 모집 조건·신청 경로·현재 기능은 실제 확인 후 반영한다. 대체 문구의 「스토어 검색·직접 매장 개설」도 자동으로 채택하지 않는다.
- 「지금은 네 통 모두 안 한다」·「사진 인증을 하면 직원이 나간다」는 확인되지 않은 효과·인과 주장이다. 그대로 사용하지 않는다.
- 앱의 화면·기능은 확인된 범위만 사용하고, 아직 기획 중이면 그 상태를 분명히 말한다.
