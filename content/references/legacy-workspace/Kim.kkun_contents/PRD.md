# PRD — Kim.kkun_contents

## 목표

김꾼 릴스의 기획·대본·편집과 성과 기록을 연결해, 수환이 소재 방향·촬영·결과 판단에 집중하며 주 단위 발행을 이어가게 한다. 부산물로 매거진형 웹사이트에 실릴 블로그 글이 같은 소재에서 나온다. 현재 승인 범위와 자동화 검증 상태는 [자동화 안내](methods/automation.md#목표-흐름)를 따른다.

## 완성 기준 (전부 예/아니오 판정)

1. 수환이 아이디어 1개를 던지면, 한 세션 안에 소재 카드가 나오고 수환이 방향을 컨펌할 수 있다.
2. 카드 확정 후 한 세션 안에 출고 패키지가 나온다: POV 제목 2~3안 / 훅 5개 / 대본 / 캡션 / 썸네일 카피 2~3안+지시. 대본은 [영상 길이·30초 벽 기준](CLAUDE.md)을 충족하고 검수 기록이 첨부돼 있다. 긴 영상은 해당 허용 조건으로 판정하며, 90초 초과만으로 탈락시키지 않는다.
3. 대본 승인 후 같은 소재에서 블로그 글 초안이 나온다.
4. 수환이 인사이트 캡처를 반입하면 archive.md에 해당 회차가 기록된다.
5. 기획 세션이 archive.md 최근 기록을 읽고 시작한 흔적(터진/죽은 패턴 언급)이 산출물에 있다.

## 4주 판정 (시스템 가설 검증)

- 발행 릴스 누적 8편 이상 (주 2편 × 4주 최소선)
- 수환 자가 판정: "기획·대본이 더 이상 병목이 아니다" — 예/아니오
- 위 둘 중 하나라도 아니오면: 병목 지점을 특정하고 시스템을 수정한다 (폐기 논의는 8주 후)

## 작업 범위

- 기획·대본 제작에 더해, 요청받은 로컬 영상 편집·내보내기와 Instagram 계정 연결·성과 조회 준비 및 검증을 포함한다. 실행 절차는 [세션 절차](methods/workflow.md), 승인 범위와 완료 판정은 [자동화 안내](methods/automation.md#목표-흐름)를 따른다.
- 촬영은 수환이 한다. 썸네일 이미지 자동 생성과 무인 자동 발행은 현재 기본 작업에 포함하지 않는다. 계정 연결·예약 수집은 실제 검증 결과에 따라 상태를 판단한다.

## 관련 결정 기록

- 설계 근거: research/projects/2026-07-25_content-system-folder-design/ (round-1·2, engine-check-1)
- 현재 영상 길이와 긴 영상 허용 조건은 [작동 지침](CLAUDE.md)이 정본이다. 기본 길이를 모든 소재의 최적 길이로 단정하지 않고 archive로 자체 실증한다.
- 블로그 역할 = 검색 유입구 + 신뢰 자산 + 근거 아카이브 (릴스→블로그 유입 기대는 구조적으로 낮음).
