# Kim.kkun_contents — 김꾼 콘텐츠 스튜디오

릴스 기획·대본과 블로그 글(매거진형 웹사이트행)을 한 소재에서 뽑는 시스템. 영상 길이와 긴 영상 허용 조건은 [작동 지침](CLAUDE.md)을 따른다.

**분업**: 수환 = 화자 (아이디어·경험담·입말·촬영). AI = 편집자 (뒤집기·구조화·검수·확장).
대본 확정 뒤 별도 지시가 없으면 비컷 3~5장면을 자율선정·이미지/영상 제작하고, 수환 검토·촬영·편집으로 이어간다. 비용 범위와 원본 촬영이 필요한 컷의 예외는 아래 정본을 따른다. 전체 제작 흐름은 [대본부터 비컷·편집까지](methods/workflow.md#대본부터-비컷편집까지--2026-09-21-수환-확정)를 따른다.

## 쓰는 법

보유 소재를 고르거나 선제작을 재개할 때는 [전체 소재 목록·준비 상태](ideas/INDEX.md)에서 해당 대본·소재 정본으로 간다.

터미널에서 이 폴더 열고 아이디어를 던진다 — 기사든 헛소리든 형식 무관.
"이거 소재 되나 봐줘" → 소재 카드 → 컨펌 → 출고 패키지(POV·훅5·대본·캡션·썸네일 카피) → 승인 → 블로그 글.
성과 반입은 매번 캡처하는 방식에서 API 자동 수집으로 전환하는 중이다. 편집 연결과 Instagram 인증·정기 실행의 실제 상태·실행 방법은 [자동화 안내](methods/automation.md)를 본다.

설계 배경: `~/Projects/research/projects/2026-07-25_content-system-folder-design/` (라운드 2회 + 3엔진 검증).

## 영상 파일 보관

2026-09-19 수환 요청으로 [김꾼 영상 작업장](../김꾼_영상보관/README.md)에 영상별 자료·결과·피드백·작업보관을 통합했다. 상세 편집 검증은 [자동화 안내](methods/automation.md#단계별-실행-확인--2026-09-19), 스타일 정본은 [편집 기준](methods/capcut-caption-style.md)을 따른다.

1. “편집하자” 요청 시 대화·대본으로 해당 편을 식별하고 `YYYY-MM-DD_소재ID/01_자료넣는곳`을 없을 때만 만든 뒤 Finder로 연다. 비컷 선제작 때 만든 보관함·장면표·채택 비컷도 함께 불러온다. 기존 자료는 재요청하지 않는다. 원본·참고자료·브금을 한곳에 받는다.
2. 자료 확인 후 승인된 로컬 편집·검수·썸네일 제작을 진행한다. `02_결과보기`에는 실제 생성·검증한 최신 검토 영상·썸네일 두 종류만 두고, 캡션은 콘텐츠 정본으로 연결한다. 사용자 최종 확정과 AI 검토본을 구분한다.
3. 새 버전의 검수가 통과하면 이전 전달본을 `99_작업보관/이전버전`으로 이동하고 링크를 갱신한다. 프로젝트 묶음·제작·검수·백업은 처음부터 `99_작업보관`에 둔다. 기존 이름으로 덮어쓰거나 불필요한 전체 사본을 만들지 않는다.
4. `03_수정기록`은 해당 편 대본·비교 기록의 콘텐츠 저장소 정본을 연결한다. 현재 상태와 과거 이력의 구분·갱신은 [영상 편집 세션](methods/workflow.md#영상-편집-세션)을 따른다. 사용자 수정 스냅샷도 보존하며, 수정 중인 타임라인을 요청 없이 바꾸지 않는다.
5. 사용자가 공통 적용으로 확정한 기준만 편집 기준 정본을 갱신한다. 반복 오류는 검사 항목으로 만들고, 다음 영상에서 시간·불필요한 사본 수·동일 오류·사용자 재수정 항목으로 효과를 확인한다. 음향·자막·화면·썸네일은 실제 출력에서 검증한다.
6. 중복·미사용이 확인된 자료는 보관함 루트 `to delete`에 이유·이전 위치와 함께 모은다. 이 이름은 삭제 승인이나 자동 삭제를 뜻하지 않는다. 원본·참조 파일·고유 백업은 유지한다.
7. 자동 보관은 알려진 영상별 폴더와 파일명 소재 ID가 일치할 때만 `99_작업보관/자동보관`에 수집한다. [수집기 안내](methods/capcut-archive/README.md)를 따른다. 이름이 불명확한 새 출력은 복사하지 않으므로 에이전트가 출력명과 해당 편 보관 완료를 확인한다. 과거 미분류는 관리자료에 보존한다.

현재 편집 정본은 CapCut 앱의 실제 프로젝트다. 로컬 보관 폴더 정리 때 참조 경로·목적지 충돌·이동 전후 해시·문서 링크·자동 보관 상태를 함께 검사한다. 보관 스크립트·옛 JSON의 경로는 과거 기록이며 그대로 재실행하지 않는다. 같은 맥 내 보관은 외부 백업이 아니고, 영상 보관함은 Git으로 보호되지 않는다.
