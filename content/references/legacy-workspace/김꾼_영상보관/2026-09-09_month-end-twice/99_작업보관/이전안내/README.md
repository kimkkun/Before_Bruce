# 월말 계산 편

기존 대본·기록과 연결하기 위해 소재 ID `2026-09-09_month-end-twice`를 사용한다. 이 날짜를 촬영일이라고 추정하지 않는다.

- `01_원본/`: CapCut 클라우드 캐시에서 확인한 편집 전 MOV를 복사했다. 별도의 촬영기기 원본과 동일한지는 확인하지 않았다. 원래 파일은 유지했다.
- `02_AI편집/`: AI 자막·타이트 컷편집 후 프로젝트와 실행 참조 ZIP. 비교 가능한 렌더링 영상은 아직 없다.
- `03_수환수정/`: 자막 분할→글꼴/강조→한 줄 보정→효과음까지 v1~v4 기록 사본. 현재 보관 기준은 v4이며 완성본 승인이나 앱의 최신 실시간 상태를 뜻하지 않는다.
- `04_최종본/`: 아직 비어 있음. 최종 승인한 내보내기 MP4와 편집 재개용 프로젝트/리소스 패키지를 함께 보관할 자리.
