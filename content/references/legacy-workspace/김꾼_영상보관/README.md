- `01_자료넣는곳`: 촬영 원본·참고자료·브금
- `02_결과보기`: 최신 검토 영상·썸네일만. 없는 결과물을 완료본으로 표시하지 않음
- `03_수정기록`: 대본·캡션·코멘트·비교 기록 정본 연결, 사용자 수정자료
- `99_작업보관`: 프로젝트 묶음·제작·검수·복원·이전 버전·자동 보관
- [to delete](to%20delete/README.md): 중복·오류·미사용 확인 자료. 실제 삭제하지 않음
- `99_관리자료`: 수집기 상태·이동 목록·소속 미확인 과거 영상

“편집하자”라고 하면 해당 편의 자료넣는곳을 열어준다. 파일을 넣은 것만으로 편집이 자동 실행되는 것은 아니다. [영상 편집 기준·보관 절차](../Kim.kkun_contents/README.md#영상-파일-보관)를 적용한다. 영상편집 시작.command는 기존 선택용 실행 파일이다.

자동 보관은 소재 ID가 일치하는 영상만 해당 편 `99_작업보관/자동보관`에 저장한다. 과거 미분류 영상은 `99_관리자료/과거미분류보관`에 보존했다. 원본·현재 CapCut 프로젝트·Movies 출력은 유지한다. 같은 맥의 보관이며 외부 백업은 아니다.
