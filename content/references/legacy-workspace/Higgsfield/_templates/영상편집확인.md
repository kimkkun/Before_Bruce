# 전체 영상 편집·보존 확인

CapCut 편집 또는 마감할 때 기존 영상별 비교 기록의 해당 항목을 보완하는 틀이다. 이미 같은 정보가 있으면 다시 복사하지 않는다. 컷마다 이 문서를 만들지 않는다.

- CapCut 플랫폼·앱 버전 / 실제 프로젝트 이름·위치 또는 Spaces 참조:
- 참조 원본·AI 컷 위치 / 사용한 컷별 버전 기록 링크:
- 큰 수정 전 프로젝트 보존본 / 대응하는 검토 MP4 버전:
- 확인한 해상도·화면비·프레임률·색 표현·음향 / 원본과 달라진 부분:
- 사용자 확정 출력 파일·발행 사용본 / 승인 근거:
- 별도 백업 위치·확인일:
- 복원 검증: 미확인 / 실제 재열기 확인
- 확인 환경·일시 / 누락 미디어·자막·음원·효과 / 재생·필요한 시험 출력 결과:

MP4와 편집 프로젝트를 구분한다. 로그인·동기화 표시나 프로젝트 폴더 복사만으로 복원 성공을 선언하지 않는다. 실제 설치 버전에서 제공되는 보존 방법을 확인하고, 원본 의존 파일이 포함된 상태로 열리는지 검증한다. 보존본이 있어도 미검증이면 그대로 기록한다.
