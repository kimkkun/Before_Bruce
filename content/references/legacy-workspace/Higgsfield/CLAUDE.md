# Higgsfield 작업 지침

1. 상위 `../CLAUDE.md`와 `../WORKING-AGREEMENTS.md`를 따른다. 이 폴더의 구성과 실제 영상 파일 위치는 `README.md`를 읽는다.
2. 요청한 방식의 README와 대상 컷 `제작기록.md`의 현재 상태부터 읽는다. 새 컷·버전은 [템플릿의 실행 명령](_templates/README.md)으로 생성·등록·검사한다. 유료 제출 전 저장 자리를 예약하고, 반환된 작업 ID를 즉시 연결한다. 전달 전 `check` 실패는 수정하고 재검사한다. 조사·과거 버전은 비교·설계 검토 때만 읽는다.
3. 김꾼 콘텐츠 제작은 `../Kim.kkun_contents/CLAUDE.md`에서 연결한 필수 문서와 대상 영상의 현재 상태를 확인한다. 공통 콘텐츠·편집 기준을 여기 복제하지 않는다.
4. 공통 제작법은 여기, 컷별 원본 참조·생성 조건·결과는 영상별 보관 위치에 둔다. 실제 원본을 덮어쓰지 않고 결과는 새 버전으로 보존한다.
5. 생성 전 실제 연결 상태·사용 가능한 모델·예상 크레딧을 확인한다. 결제·크레딧 사용은 상위 승인 기준과 기존 승인 범위를 따른다. 키·토큰·비밀번호는 문서에 저장하지 않는다.
   - 생성 응답이 끊겼거나 완료 상태가 불명확하면 [Orchestrator의 실행·복구 절차](../Orchestrator/workflows/new-work.md#3-작은-구조를-정해-실행하기)에 따라 기존 작업 ID·실제 상태부터 확인한다. 상태 미확인으로 새 유료 생성을 중복 제출하지 않는다.
6. 폴더·문서 존재를 제작 완료나 계정 연결 성공으로 간주하지 않는다. 검토한 프레임·구간·오디오 등 실제 확인 범위와 한계를 보고한다.
