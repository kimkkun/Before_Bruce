# 영상 제작 관리 조사 · 2026-09-20

설계 근거를 확인할 때만 읽는 참고자료. 현행 작업 순서는 상위 README와 템플릿이 정본이다.

## 결론과 적용

세 제작 방식의 공통 안내를 유지하고, 실제 파일은 영상 → 제작 방식 → 컷 → 버전 순으로 묶는다. 산업 전체에 통용되는 단 하나의 완벽한 폴더는 찾지 못했다. 대규모 영화 제작 체계를 그대로 가져오는 대신, 수환의 CapCut·촬영/AI 혼합 제작에 필요한 추적·검토·보존 요소만 적용했다.

## 반례와 미확인

- Frame.io 실무자도 프로젝트 필요·인력·자원에 맞춘 구조를 강조한다. 컷마다 전체 CapCut 프로젝트를 복제하거나 대규모 EXR·컬러 파이프라인을 의무화하지 않았다. [1]
- CapCut 문서의 로그인 시 클라우드 저장 설명과 Spaces 업로드 필요 설명이 함께 있어, 로그인만으로 실제 백업을 판정할 수 없다. 모바일 템플릿의 플랫폼 간 표시 차이도 공식 도움말에 나온다. 실제 설치 버전의 백업·재연결 방법은 이번 조사에서 검증하지 않았다. [2][6]
- Higgsfield API의 최소 7일 결과 보존 설명은 API에 한정된다. 웹·플러그인의 보존 기간으로 일반화하지 않는다. 로컬 다운로드를 원칙으로 삼되 외부 백업과는 구분한다. [7]
- 폴더·짧은 지침만으로 생성 품질이나 할루시네이션 방지를 보장하지 않는다. 첫 실제 컷에서 얼굴·연기·편집 호환성·피드백 반영과 기록 부담을 검증해야 한다.

## 조사 실행과 비용

- 수환 승인: 2026-09-20 대화의 “최대 1달러까지 승인”. 대상은 이번 폴더 설계 조사를 위한 Exa·Tavily·Brave 기본 검색이며 이후 반복 조사나 영상 생성의 포괄 승인이 아니다.
- 사용 스킬: 로컬 `multi-engine-research` 1.0.0. 전략은 분야별 분담. Exa는 VFX 관리, Tavily는 CapCut 보존·예외, Brave는 Higgsfield 입력·제작·보존을 조사했다.
- Codex에는 Claude 플러그인 도구가 직접 노출되지 않아, 설치된 동일 MCP 서버를 임시 stdio 호출기로 연결하고 세 하위 에이전트의 검색 엔진을 분리했다. 다른 검색엔진으로 대체하지 않았다.
- 각 엔진: 최초 샌드박스 네트워크 실패 1회, 정식 권한 상승 경로 재시도 후 성공 검색 2회. 합계 9회 시도 / 6회 성공 / 3회 실패. 각 엔진 3회 상한을 지켰으며 고급 연구·크롤링·유료 본문 추출 도구는 호출하지 않았다.
- 검색 결과의 공식 원문은 기본 웹 도구로 열어 검증했다(에이전트 각 2개, 총괄 보완 3개). 가격 확인은 별도 기본 웹 검색을 사용했다. 세 엔진이 같은 CapCut 문서를 찾은 것은 독립 출처 세 개로 세지 않았다.
- 공개 기본 단가로 성공 검색 6회의 검색료는 약 $0.04 예상(Exa $0.007×2, Tavily $0.008×2, Brave $0.005×2). Exa 본문 제공 등 부가 항목과 요금제에 따라 달라질 수 있어 실행 예산은 $0.10 미만으로 보수적으로 잡았으며, 실제 청구액·무료 잔액은 미확인이다. $1 한도까지 검색을 계속하지 않고 6회 성공 후 종료했다. [8][9][10]
- 원시 응답·엔진별 보고서는 이번 세션 임시 경로 `/private/tmp/higgsfield-research-20260920/`에 있다. 임시 파일은 영구 보존이나 지침의 일부가 아니다. 재사용할 결론·출처·실행 범위는 이 문서에 남긴다.
