- https://higgsfield.ai/creator-hub/help-center/ai-models/how-do-i-use-seedance : 짧은 이미지 기반 시험, 구체적 동작·환경·카메라 지시, 전체 영상 검토, 반복 때 한 요소씩 수정 권장.

## 이번 요청에 대한 제작 후보 — 아직 미검증
‘주변 직원이 사라지고 불이 꺼져 혼자 남음’은 AI가 제안한 예시이며 수환의 확정 장면은 아니다.
- 먼저 대사·삽입 지점·시청자에게 전달할 의미와 시작/변화/끝을 정한다. 마지막 빈 매장 이미지 한 장은 사라지는 순서나 소등 타이밍을 지정하지 못한다.
- 원본 인물·입 모양 보존이 우선이면 원본 인물을 분리하고, 직원이 있는/없는 배경과 조명 변화를 별도로 제작·합성하는 후보를 우선 비교. 경계·손/마이크 가림·인물 재조명 비용도 평가해야 하며 쉽거나 성공 보장이라고 하지 않는다.
- 장면 전체의 재생성이 허용되면 시작·끝 참고 이미지와 단계별 행동을 지원하는 현재 모델을 확인해 짧게 시험. 인물 정체성·동작·소등 순서가 함께 흔들릴 수 있다.
- 정확한 순차 변화가 한 번에 안 되면 여러 상태를 별도 컷으로 만들고 편집 연결. 원본에 없는 연기는 별도 촬영 또는 새 생성이 필요한지 먼저 판단.
- 새 카메라 각도는 별도 문제. 실제 원본 프레임을 확인한 뒤 목표 시점을 시각화하고 맞는 기능을 시험한다. 원본 모션 보존만으로 새 시점이 만들어진다고 보장하지 않는다.

## 기록 구조 점검
- 기존 지침에 목적·통과 기준·원본 확인·피드백 보관이 이미 있음. 이번 실패를 검수 규칙 부재로 진단하지 않는다.
- 실제 실패 기록은 영상별 제작기록에 두고, 제작방식 README에서 관련 사례를 찾도록 연결한다. 원문이나 전체 연구를 공통 필독에 복제하지 않는다.
- 모델 자체의 자동 학습/상주 에이전트/자동 회고 구현은 아님. 다음 에이전트가 연결 지침을 읽어 이전 입력·결과·평가를 반영하는 문서 기반 재사용 구조.
- 생성 성공, 기술 검수, 사용자 채택을 구분. 단일 성공은 재현성 증명이 아니다.
- 다음 실제 작업에서 이전 실패가 제안/입력 선택에 반영되는지 확인해야 개선 효과를 검증할 수 있음. 현재는 기록·연결 보완까지만 확인.
