# Soul ID 인물 기반 고품질 영상 제작법 조사 — 2026-09-21

## 요청과 조사 범위

수환 요청: 촬영 토킹헤드의 환경 변환과 별도로, 김꾼 Soul ID로 원하는 상황을 더 디테일하고 세련되게 만드는 방법론을 멀티 에이전트로 조사하고 지침화. 3개 에이전트가 정체성/모델 전달, 영화적 장면 설계/공개 제작 사례, 로컬 구조/검수 절차를 분담했다. 총괄은 근거 충돌과 현재 MCP 모델 스키마를 대조했다. 생성·유료 실행 없음.

메인 갤러리의 모든 클립을 실제 재생하거나 제작 이력을 확보한 것은 아니다. 공식 Help Center와 제작팀이 공개한 과정에 근거하며, 미감 평가·모델 우열·재현율은 별도 실증이 필요하다. 아래 운영 방법은 조사 기반 절차이지 새 김꾼 영상으로 검증한 성공법이 아니다.

## 핵심 판정

Soul ID는 정체성 재료다. 장면의 의미, 세트와 소품 관계, 빛과 구도, 동작의 인과관계, 편집과 소리를 별도로 설계한다. 완성도 높은 기준 이미지를 선택한 뒤 움직임을 시험하는 것이 기본 경로다. 'cinematic/8K/ARRI' 같은 형용사나 장비명 추가만으로 품질을 보장하지 않는다.

## 1차 출처와 적용 범위

1. [Soul ID Help Center](https://higgsfield.ai/creator-hub/help-center/ai-models/how-do-i-create-and-use-a-soul-id-character): Soul 계열의 정체성 기능과 외부 영상 모델의 Element 전달을 구분. 같은 사람으로 인식되는 수준이며 극단적 각도/스타일의 얼굴 변화 가능성 명시. 모든 영상 모델이 soul_id를 직접 받는다는 근거가 아님.
2. [Soul 이미지 Help Center](https://higgsfield.ai/creator-hub/help-center/ai-models/how-do-i-use-soul-to-generate-images): Soul ID/스타일/색 조절 기능. 웹 UI는 참조 이미지를 붙이면 텍스트 프롬프트가 비활성화된다고 설명. API도 반드시 같은 제약이라고 추정하지 않는다.
3. [Soul Cinema Help Center](https://higgsfield.ai/creator-hub/help-center/ai-models/how-do-i-use-soul-cinema): Soul Cinema는 영상 시작 프레임 후보인 이미지 모델. Soul 계열 캐릭터 공유 및 필요시 업데이트 절차 안내. 현재 계정의 업데이트·ID 호환은 실증하지 않음.
4. [Seedance Help Center](https://higgsfield.ai/creator-hub/help-center/ai-models/how-do-i-use-seedance): 짧은 720p 이미지 기반 시험, 행동/환경·빛/카메라/분위기 지시, 전체 재생 검토 후 한 변수씩 수정 권고. 실행 시 모델별 실제 입력·비용 확인 필요.
5. [Cinema Studio Help Center](https://higgsfield.ai/creator-hub/help-center/tools/how-do-i-use-cinema-studio): 프로젝트 공통 룩과 개별 샷의 카메라·참고 자산을 나눠 관리. 웹 기능이 현재 MCP에 모두 노출된다고 해석하지 않는다.
6. [Cinema Studio 제작기](https://higgsfield.ai/blog/how-we-built-cinema-studio): 제작팀은 프롬프트 결과를 촬영 전문가와 검토했고 실제 광학과 같은 시뮬레이션이 아니라고 설명. 렌즈 이름보다 실제 얻은 화면을 평가할 근거.
7. [AI vs VFX 공개 제작 과정](https://higgsfield.ai/blog/ai-vs-vfx): 인물/용/장소와 상대 크기를 보이는 참고자료를 준비. 원본에 필요한 동작이 없어 반복 실패한 컷은 이미지 기반 생성과 편집으로 방식 변경. 특정 모델 우열·비용/성공률 주장은 일반화하지 않음.
8. [사람 동작 제작 가이드](https://higgsfield.ai/blog/realistic-ai-human-movement): 야구 장면에서 시선·몸통 회전·체중 이동·타격·후속 동작을 연결. 3~5초 비컷에는 하나의 주동작부터 시험하는 것은 우리 적용 제안. Soul ID가 모든 모델에 자동 적용된다는 포괄적 마케팅 문구는 Help Center/실제 스키마보다 우선하지 않음.
9. [API 제작 예시](https://higgsfield.ai/blog/generate-ai-videos-higgsfield-api): 인물 이미지→시각 설계→이미지 기반 영상의 한 경로를 제시. Soul 2→Soul Cinema→Kling을 모든 컷의 필수 3단계로 강제하지 않는다.

## 실제 도구 확인 — 2026-09-21 읽기 전용

- models_explore get soul_2: 이미지 모델, soul_id 지원, 참조 이미지 최대 1개, 1.5k/2k, 9:16 포함.
- models_explore search soul cinema: soul_cinematic 이미지 모델, soul_id 설명은 'Soul Cinema Character ID', 참조 이미지 최대 1개. 기존 김꾼 최종 ID를 그대로 넣어 성공하는지는 미검증.
- 지원 입력이 맞는지 먼저 확인하고, Soul에서 채택한 이미지를 영상 모델의 start_image/참조/Element로 전달한다. 복수 참조 설계와 실제 한 요청의 허용 개수는 다를 수 있다.
- 계정 캐릭터/요소 목록은 이번에 재조회하지 않았다. 기존 사용 ID는 과거 컷 기록에서 찾고 다음 생성 전에 준비 상태를 다시 확인한다.

## 로컬 감사 — 없는 규칙을 늘리지 않기

기존 컷/버전 템플릿에 장면 목적·통과 기준·유지/변경·카메라/조명/음향·피드백과 검수 범위가 이미 있다. 새 양식은 만들지 않는다.
기존 owner-three-points S01/S02는 Soul 2 2K→Kling 3 5초, 조명·색·단일 동작·물리·접촉 지시도 이미 있었다. 실제 보완점은 시각 후보 비교·선택과 전체 재생 검수다. 기록상 0/2/4초 축소 프레임만 확인했고 손 연속성·세밀한 얼굴 검수는 미완료였다. 이번 연구에서 기존 영상을 새로 재생해 미감을 평가한 것은 아니다.

## 김꾼 적용 예 — 제작 전 가설

'사장이 매장을 떠받친다'를 예로 들면: 얼굴만 닮게 만드는 것에 더해, 두 손과 구조물의 접점, 몸 대비 매장의 크기, 버티는 체중과 발 위치가 읽히는 기준 프레임을 먼저 만든다. 영상은 무게가 실리며 무릎이 조금 굽는 한 사건과 필요한 먼지/천의 반응부터 시험한다. 느린 카메라 접근은 압박감을 보탤 때만 사용한다. 이 예는 수환의 확정 장면/취향이 아니며 제작하지 않았다.
