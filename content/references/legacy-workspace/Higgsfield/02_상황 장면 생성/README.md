# 02 상황 장면 생성

특정 인물의 얼굴을 유지하는 것이 목적이 아닌, 대본의 맥락을 돕는 장면을 만드는 방식. 로켓 발사·접시 파손·텅 빈 가게처럼 사물·공간·사건을 표현한다.

- 입력: 대본 구간, 장면이 전달할 의미, 참고 이미지나 영상.
- 기획: 필요한 길이·화면비, 사건 전후 상태, 움직임 순서, 구도·카메라·조명과 앞뒤 편집 연결을 정한다.
- 검수: 맥락 전달, 물체의 형태·개수 유지, 중력·충돌 등 움직임, 사건의 순서, 앞뒤 컷과의 연결을 확인한다. 화려함만으로 채택하지 않는다.
- 보관: [공통 안내](../README.md#실제-영상-파일의-위치)에 따라 해당 영상의 `02_상황 장면 생성/S번호_장면이름/`에 생성 조건과 결과 버전을 둔다.

새 컷은 [공통 템플릿](../_templates/README.md)을 사용한다. 위 항목은 제작 시작용 체크리스트다. 재사용할 장면은 원래 파일의 위치와 사용 사례를 연결하고, 공통 라이브러리는 실제 재사용 수요가 생기면 구성한다.
