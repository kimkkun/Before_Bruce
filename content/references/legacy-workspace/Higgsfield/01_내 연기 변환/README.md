# 01 내 연기 변환

직접 찍은 연기를 바탕으로 의상·배경·상황을 바꾸는 방식.

## 현재 제작 기준 — 2026-09-21 수환 확정

적용 범위: 수환이 직접 촬영한 토킹헤드를 활용해 AI 비컷으로 배경·상황을 바꾸는 작업. 사용자 요청 “내가 찍은 영상의 제작 방법은 이렇게 일단은 잡자 이렇게 하라고 지침에 넣어놔봐”로 아래 방식을 현재 기본으로 채택했다. 모델의 자동 학습이나 모든 컷의 성공을 보장하는 규칙은 아니다.

### 촬영 준비

- 본편 토킹헤드는 기존의 가까운 구도로 촬영할 수 있다.
- 주변 인물·공간·사건을 보여줄 AI 변환 구간만 같은 대사를 넓은 구도로 추가 촬영한다. 허리 정도까지 보이고 좌우·머리 위에 변화가 일어날 공간을 남긴다. AI는 필요한 추가 구간과 동작을 촬영 전에 알려준다.
- 기존 원본을 활용할 때는 실제 해당 구간의 얼굴·안경·손·마이크·가림·배경 여유를 먼저 확인한다. 좁은 구도에 맞지 않는 연출을 억지로 넣거나 별도 촬영 없는 새 시점을 보장하지 않는다.

### 제작 순서

1. **대사와 장면 설계:** 삽입할 실제 발화, 전달할 의미, 시작→변화→끝, 길이를 정한다. 새 연출은 관련 제작 사례·현재 도구 지원·원본 적합성을 먼저 조사하고 기존 성공/실패 기록과 대조한다.
2. **참고 이미지:** 원본 프레임을 기준으로 바뀔 공간·조명·인물 배치를 시각화한다. 시간에 따른 변화가 있으면 마지막 분위기 이미지뿐 아니라 시작 상태와 변화 순서도 준비한다. 이미지 모습 확인과 영상 연출의 채택은 구분한다.
3. **원본 연기 적용:** 참고 이미지와 원본 짧은 구간을 Higgsfield Motion Transfer 등 목적에 맞는 기능에 넣어 연기를 적용한다. 참고 이미지는 모습·공간, 원본 영상은 움직임·타이밍의 기준으로 명시한다.
4. **상황 변화 구현:** 직원 소멸·소등처럼 시간 순서가 필요한 컷은 준비된 영상과 시작 참고 이미지를 바탕으로 지원되는 영상 편집 모델에 단계별 지시를 넣는다. 해당 변화가 없는 컷은 이 단계를 생략한다. 검증한 결과를 재사용하고 불필요한 재생성은 피한다.
5. **음성·편집·검수:** 필요한 경우 원본 음성을 연결하고, 원본과 결과의 얼굴·손·마이크·입 모양·타이밍을 비교한다. 전체 재생으로 장면 변화와 소리를 확인하고 실제 확인 범위·남은 결함을 기록한다. 생성 완료만으로 본편 사용 가능이라고 하지 않는다.
6. **다음 작업으로 연결:** 사용자 평가와 채택 여부는 컷별 제작기록, 실제 입력·프롬프트·모델·비용·출력·검수는 버전별 생성정보에 남긴다. 다음 유사 작업에서 관련 사례를 먼저 읽고 적용하되 한 번의 성공을 재현성 검증 완료로 취급하지 않는다.

제작 단계별 도구를 구분해 설명한다. 이미지 시안과 Higgsfield 영상 생성, 원본 음성 연결·편집을 모두 Higgsfield 단일 생성처럼 말하지 않는다. 사용 가능한 모델과 비용·승인 범위는 실제 실행 전에 확인한다.

보관은 [공통 안내](../README.md#실제-영상-파일의-위치), 새 컷·버전은 [공통 템플릿](../_templates/README.md)을 따른다. 기존 결과는 보존하고 새 버전으로 수정한다.
